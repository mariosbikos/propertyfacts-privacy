# PropertyFacts — privacy policy

Published at <https://mariosbikos.github.io/propertyfacts-privacy/>.

This repository exists only to give the privacy policy a **public, permanent
URL**. The Chrome Web Store requires one, and the extension's own repository is
private — GitHub Pages will not serve a private repo without a paid plan.

Keeping it separate has a second benefit: the URL does not change if the main
repository is later made public, renamed, or moved. A store listing that points
at a dead policy link is a compliance problem.

`index.md` is a copy of `PRIVACY.md` from the extension repository. **Edit it
there first**, then copy it here — the extension's test suite asserts that every
host in `manifest.json` `host_permissions` is disclosed in that file, so the
canonical copy is the one under test.
